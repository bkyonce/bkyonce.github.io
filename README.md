# Buturo Bartolomei — Cybersecurity Portfolio

A lightweight static portfolio built with plain HTML, CSS, and a tiny amount of JavaScript. It is ready for GitHub Pages and does not require a build step.

## Structure

```text
.
├── index.html
├── homelab/index.html
├── experience/index.html
├── notes/index.html
└── assets/
    ├── css/styles.css
    ├── js/main.js
    └── favicon.svg
```

## Publish with GitHub Pages

1. Create a public GitHub repository, such as `cybersecurity-portfolio`.
2. Upload everything in this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide a URL similar to `https://YOUR-USERNAME.github.io/cybersecurity-portfolio/`.

## Customize

- Edit the text directly in each `index.html` file.
- Change the color variables at the top of `assets/css/styles.css`.
- Replace roadmap language with completed results only after the work is finished.
- Add screenshots under a new `assets/images/` folder and use descriptive `alt` text.
- Add a resume PDF only after updating it to show Security+ as earned.

## Good homelab entry format

For every project, document the objective, architecture, implementation, test evidence, security considerations, problems encountered, and what you would change next time. Never publish passwords, API keys, public IP addresses, device serial numbers, or unsanitized configuration.
